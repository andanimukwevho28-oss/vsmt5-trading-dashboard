# MT5 project scaffold

This folder is prepared as a MetaTrader 5 MQL5 project skeleton.

## Folder layout

- `MQL5/Experts/MT5StarterEA.mq5` — example Expert Advisor
- `MQL5/Include/MT5Helper.mqh` — helper include file

## How to use it in MT5

1. Open MetaEditor in MetaTrader 5.
2. Create a new Expert Advisor project or copy this folder structure into your MT5 installation under `MQL5`.
3. Compile the EA.
4. Attach it to a chart in MetaTrader 5.

## Notes

- This environment here cannot launch MetaTrader 5 itself, so the code is prepared for MT5 compilation, not for direct execution in this VS Code workspace.
- If you want a different MT5 strategy type (indicator, script, or signal), I can convert this scaffold to that format.
